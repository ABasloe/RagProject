Analysis of Algorithms RAG Search Algorithm Project
Aidan Basloe, Josh Pomeroy
Abstract
	This paper will aim to uncover the role of specific algorithms when it comes to Retrieval-Augmentated Generation (RAG) AI frameworks. In the retrieval period of the process, embedded data inputs are compared to other data to look at the similarity levels. This similarity is calculated in many different ways with each algorithm having benefits and drawbacks mainly centering around speed of access, precision of similarity scores, memory efficiency, and token usage. Nearest Neighbor Search (NNS) is the overarching task but specific algorithms include: exact closest neighbor, the widely used Approximate Nearest Neighbor Search (ANNS), Locality-Sensitive Hashing (LSH), linear search, and BK-tree methods. These search algorithms along with the databases stored in, the embedding models used, and the rag implementations themselves create an in depth system of algorithms all working in conjunction to improve the models abilities.
